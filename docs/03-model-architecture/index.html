03 · Model Architecture

Three Encoders, One Attention Pool, Three Ways to Fuse

Each modality gets its own encoder that turns raw data into a fixed-length embedding. What differs between the three architectures in this course is only how those embeddings get combined — everything else (the pooling method, the prediction head) is held identical, so the comparison isolates the fusion mechanism itself.

Tabular Encoder

def extract_patch_embeddings(wsi_path, coords, patch_size, patch_level, model, transform, device):
    """Run the encoder over every (x, y) patch coordinate; return (N, 1536)."""
    captured = {}
    handle = model.blocks[-1].register_forward_hook(
        lambda module, inp, out: captured.update(last_block=out.detach())
    )
    slide = openslide.OpenSlide(str(wsi_path))
    embeddings = []
    for batch_coords in chunks(coords, 256):
        patches = [slide.read_region((x, y), patch_level, (patch_size, patch_size)).convert("RGB")
                   for x, y in batch_coords]
        batch = torch.stack([transform(p) for p in patches]).to(device)
        with torch.no_grad():
            model(batch)
        embeddings.append(captured["last_block"][:, 0, :].cpu().numpy())  # CLS token, last block
    handle.remove()
    return np.concatenate(embeddings, axis=0)

Step 2 · MIL Pooling — ABMIL

A whole-slide image doesn't give the model one vector — it gives a bag of hundreds to thousands of patch embeddings. Attention-based multiple-instance learning (ABMIL) turns that variable-size bag into one fixed vector, by learning which patches matter most instead of averaging them uniformly:

class ABMIL(nn.Module):
    """Attention-based MIL pooling: a bag of N patch embeddings -> one bag-level vector,
    weighting each patch by a learned attention score instead of averaging uniformly."""
    def __init__(self, input_dim: int, hidden_dim: int = 128):
        super().__init__()
        self.attention = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.Tanh(), nn.Linear(hidden_dim, 1),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """x: (N, D) patch embeddings for one WSI -> (D,) bag-level embedding."""
        attn_scores = self.attention(x)               # (N, 1)
        attn_weights = F.softmax(attn_scores, dim=0)  # (N, 1)
        return (attn_weights * x).sum(dim=0)          # (D,)

Step 3 · Prediction Head

Every fusion strategy also shares the same head architecture — a 3-layer MLP — for both downstream tasks. Only the output dimension changes: one logit for classification, one hazard logit per discrete time bin for survival.

class PredictionHead(nn.Module):
    def __init__(self, input_dim: int, output_dim: int, hidden_dim: int = 64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.BatchNorm1d(hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim // 2), nn.BatchNorm1d(hidden_dim // 2), nn.ReLU(),
            nn.Linear(hidden_dim // 2, output_dim),
        )

    def forward(self, x):
        return self.net(x)

def build_task_head(input_dim, task, num_time_bins=15):
    if task == "classification":
        return PredictionHead(input_dim, output_dim=1)
    return PredictionHead(input_dim, output_dim=num_time_bins)  # task == "survival"

Step 4 · Three Fusion Strategies

With the shared building blocks fixed, here's what actually changes between the three architectures — where and how the three modalities meet.

Early Fusion

Concatenate everything before any joint modeling, then let one shared trunk do the work. Since WSI (1536-dim) and MRI (2048-dim) would otherwise dwarf the 22-dim clinical vector by sheer feature count, each modality vector is L2-normalized before concatenation; the fused vector is then BatchNorm'd as a single block.

class EarlyFusionModel(nn.Module):
    def __init__(self, wsi_dim=1536, mri_dim=2048, clinical_dim=22, hidden_dim=256,
                 task="classification", num_time_bins=15):
        super().__init__()
        self.abmil = ABMIL(wsi_dim, hidden_dim=128)
        fused_dim = wsi_dim + mri_dim + clinical_dim
        self.input_norm = nn.BatchNorm1d(fused_dim)
        self.trunk = nn.Sequential(
            nn.Linear(fused_dim, hidden_dim), nn.ReLU(), nn.Dropout(0.2),
            nn.Linear(hidden_dim, hidden_dim // 2), nn.ReLU(),
        )
        self.head = build_task_head(hidden_dim // 2, task, num_time_bins)

    def forward(self, batch):
        wsi_pooled = torch.stack([self.abmil(w) for w in batch["wsi"]])
        wsi_pooled = F.normalize(wsi_pooled, p=2, dim=1)
        mri = F.normalize(batch["mri"], p=2, dim=1)
        clinical = F.normalize(batch["clinical"], p=2, dim=1)
        fused = self.input_norm(torch.cat([wsi_pooled, mri, clinical], dim=1))
        return self.head(self.trunk(fused))

Intermediate Fusion

Each modality first gets its own projection into a shared 256-dim space, then one round of self-attention lets the three modality tokens attend to each other before mean pooling. One attention pass is enough to demonstrate what "intermediate" fusion means — a deeper transformer stack would push this model's parameter count far past the other two on a ~95-patient cohort.

class IntermediateFusionModel(nn.Module):
    def __init__(self, wsi_dim=1536, mri_dim=2048, clinical_dim=22, shared_dim=256,
                 task="classification", num_time_bins=15):
        super().__init__()
        self.abmil = ABMIL(wsi_dim, hidden_dim=128)
        self.proj_wsi = nn.Linear(wsi_dim, shared_dim)
        self.proj_mri = nn.Linear(mri_dim, shared_dim)
        self.proj_clinical = nn.Linear(clinical_dim, shared_dim)
        self.self_attn = nn.MultiheadAttention(embed_dim=shared_dim, num_heads=4, batch_first=True)
        self.attn_norm = nn.LayerNorm(shared_dim)
        self.head = build_task_head(shared_dim, task, num_time_bins)

    def forward(self, batch):
        wsi_pooled = torch.stack([self.abmil(w) for w in batch["wsi"]])
        tokens = torch.stack([
            self.proj_wsi(wsi_pooled), self.proj_mri(batch["mri"]), self.proj_clinical(batch["clinical"]),
        ], dim=1)                                               # (B, 3, shared_dim)
        attn_out, _ = self.self_attn(tokens, tokens, tokens)     # one round of cross-modal attention
        tokens = self.attn_norm(tokens + attn_out)
        return self.head(tokens.mean(dim=1))

Late Fusion

Each modality gets a fully independent prediction head — they never share an intermediate representation. The three independent predictions are combined only at the very end, through a learned per-modality weight.

class LateFusionModel(nn.Module):
    def __init__(self, wsi_dim=1536, mri_dim=2048, clinical_dim=22,
                 task="classification", num_time_bins=15):
        super().__init__()
        self.abmil = ABMIL(wsi_dim, hidden_dim=128)
        self.wsi_head = build_task_head(wsi_dim, task, num_time_bins)
        self.mri_head = build_task_head(mri_dim, task, num_time_bins)
        self.clinical_head = build_task_head(clinical_dim, task, num_time_bins)
        self.modality_logits = nn.Parameter(torch.zeros(3))     # learned combination weights

    def forward(self, batch):
        wsi_pooled = torch.stack([self.abmil(w) for w in batch["wsi"]])
        out = [self.wsi_head(wsi_pooled), self.mri_head(batch["mri"]), self.clinical_head(batch["clinical"])]
        weights = F.softmax(self.modality_logits, dim=0)
        return sum(w * o for w, o in zip(weights, out))

LateOnly at the output — weighted sum of independent predictionsNo — fully independent heads
All three architectures are parameter-count-matched at the fusion stage on purpose, so that differences observed in Evaluation reflect the fusion mechanism, not one model simply having more capacity than another.
